# Provenance: what derives from PS2Recomp

The port is GPL-3.0 (decision D3.4, 2026-11-02). PS2Recomp
(ran-j/PS2Recomp, GPL-3.0, commit `e5636981`) is forked for its runtime;
the code generator is ours. This file lists which of our code derives from
PS2Recomp. PS2Recomp's sources, our patch to them, generated code and
recordings stay in `private/` (condition 4).

## In `private/` (not in the repo)

| Path | Derived? | What |
|---|---|---|
| `private/third_party/PS2Recomp/` | is PS2Recomp | the checkout |
| `private/third_party/trial/ps2recomp-trial.patch` | yes | our changes to PS2Recomp (PHASE_3 B3) |
| `private/third_party/trial/out-*/` | generated by PS2Recomp from the game | |
| `private/third_party/trial/harness/shim.cpp` | yes, by design | stand-in for PS2Recomp's runtime; its dispatch and checkpoint logic mirror `ps2_runtime.cpp` / `EeScheduler.cpp` |
| `private/third_party/trial/harness/harness_fast*.h` | yes | replacement definitions of PS2Recomp's GPR and memory macros, same semantics |
| `private/third_party/trial/harness/main.cpp`, `make_harness.py`, `build.sh` | no (built against PS2Recomp's headers) | replay driver and tooling |

## In the repo

| Path | Derived? | Notes |
|---|---|---|
| `scripts/*` | no | `ps2recomp_trial.sh` and `compile_generated.sh` drive PS2Recomp's tools but contain none of its code |
| `docs/*` | no | describe PS2Recomp's behaviour from reading and running it |

Update this table whenever code moves from `private/` into the repo or our
generator takes semantics from PS2Recomp's emitter.
